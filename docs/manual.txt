1. Objetivo
Este documento tem por objetivo fornecer as orientações técnicas necessárias
para integração de sistemas externos de obras a Planilha Orçamentária do
módulo de Projeto Básico da plataforma Transferegov.
A API foi criada com o intuito de possibilitar a integração de sistemas externos
diminuindo assim o esforço e retrabalho na elaboração do orçamento e
cronograma na etapa de elaboração do Projeto Básico, buscando evitar as
inconsistências que podem ocorrer ao se registrar de forma manual os mesmos
dados em vários meios. Uma vez que o sistema externo esteja integrado ao
Transferegov.br, não haverá necessidade de replicação dos dados de forma
manualmente.

2. Protocolo de Comunicação
O protocolo de comunicação utilizado é o REST - Representational State Transfer/ HTTP 1.1 e
os dados trafegados utilizam a notação JSON - JavaScript Object Notation.

3. Autenticação e validação
Para utilização da API do Transferegov.br é necessário que o usuário Convenente esteja
autenticado e que o sistema externo esteja habilitado com token ativo.

3.1 Autenticação do usuário
O usuário da aplicação deverá estar autenticado e possuir um dos seguintes perfis:
Operador Financeiro do Convenente, Gestor de Convênio do Convenente,
Gestor Financeiro do Convenente. A autenticação bem-sucedida retorna um Token JWT
(JSON Web Token) com os dados do usuário criptografados, esse token servirá como
parâmetro do Authorization Header de cada requisição. Nas consultas, o usuário pode
logar com qualquer perfil do Transferegov.br. Na inserção, será validado se o usuário é
proponente/convenente da proposta do respectivo Projeto Básico que pretende
atualizar.

3.1 Autenticação do sistema
O sistema externo deve solicitar sua habilitação para uso da API do Projeto Básico por
meio das orientações presentes no endereço: https://www.gov.br/transferegov/ptbr/sobre/apis-integracao/sistemas-de-obras. No momento do cadastro e habilitação do
sistema externo, será enviado um e-mail para os responsáveis técnicos do sistema
externo com o Token JWT de acesso que identificará unicamente o sistema externo e
permitirá a confirmar a habilitação no acesso aos serviços desejados. Este deve ser
adicionado como parâmetro EP-CAD no Header da solicitação.

Básico na aba PO/CFF na sub aba Dados Gerais, a opção “Receber dados da PO/CFF via API?”.

5.2. Enviar Planilha Orçamentária de uma Submeta
Este serviço permite enviar os dados da submeta do Projeto Básico no que se refere a
Planilha Orçamentária, Frente de Obra, Eventos, quando houver, e CFF. A depender se a
submeta será acompanhada por eventos ou não, o layout de envio do json pode ser no
formato da Planilha de Levantamentos de Eventos (PLE) quando acompanhada por eventos
ou no formato do Boletim de Medição (BM) quando não acompanhada por eventos.
